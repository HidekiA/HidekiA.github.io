# HidekiA's Personal Website

This is the source code for my personal portfolio and academic profile website.

🌍 **Live Site:** [https://hidekia.github.io](https://hidekia.github.io)

## 🛠 Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **Styling:** CSS
- **Content:** Markdown / MDX
- **Hosting:** GitHub Pages

## 🚀 Local Development

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/HidekiA/HidekiA.github.io.git
   cd HidekiA.github.io
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:4321`.
