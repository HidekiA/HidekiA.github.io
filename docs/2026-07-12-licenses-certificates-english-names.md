# Licenses & Certificates 英語表記の出典調査(2026-07-12)

`src/content/licenses.yaml` に掲載している各免許・資格の英語表記について、
公式な英語名称が存在するかを調査した記録。対象は Web 検索で確認できた範囲。

## 表記の分類

- **公式** — 発行団体・監督官庁の公式サイト/公式資料に明記された英語名称。今回修正済み。
- **国際ブランド表記(慣例)** — AWS・Google Cloud 等、海外企業が公式に定めた
  認定名の型に合わせた表記。海外系のため個別の Web 検索での再確認はしていないが、
  既知のブランド命名規則に基づく。
- **未確認(機械翻訳/意訳)** — 日本国内限定の資格・検定で、発行団体の英語版サイトに
  英語名称が見当たらない、または検索で単一の公式表記を特定できなかったもの。
  現状の英語表記は直訳・意訳であり、"公式" ではない。

## 今後の対応について

「未確認」欄の項目は、必要であれば発行団体に個別に問い合わせるか、
各資格証書に記載された英語表記(あれば)を確認して反映するのがもっとも確実。
